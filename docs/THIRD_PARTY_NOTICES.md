# Third-party software

This browser edition includes the following self-hosted packages:

- `@ffmpeg/ffmpeg` 0.12.15 — MIT license — <https://github.com/ffmpegwasm/ffmpeg.wasm>
- `@ffmpeg/core` 0.12.10 — GPL-2.0-or-later — <https://github.com/ffmpegwasm/ffmpeg.wasm>

The WebAssembly core is used for local video transcoding in the browser. Distributors are responsible for complying with the applicable open-source licenses and making the corresponding source available as required.
